# Fixora — AI Code Repair & Analysis

> Your personal senior engineer, available 24/7.

## ✨ Features
- 🔍 **Instant Analysis** — detect bugs, security issues, code smells in any file
- 🛠️ **AI-Powered Repair** — get verified, explainable fixes before they touch your disk
- 💬 **Explain Issues** — understand WHY something is wrong, not just what
- 🛡️ **Code Shield** — real-time PR readiness score (0–100) on every save
- 🔌 **Works Standalone** — no desktop app needed, just add your API key

## 🚀 Quick Start
1. Install the extension
2. Open **Command Palette** → `Fixora: Setup`
3. Add your OpenAI / Anthropic / Gemini / OpenRouter API key
4. Open any file → run `Fixora: Analyze`

## 🎯 Commands
| Command | Description |
|---------|-------------|
| `Fixora: Analyze` | Analyze current file for issues |
| `Fixora: Repair` | AI-repair the selected issue |
| `Fixora: Explain` | Explain why this is an issue |
| `Fixora: Setup` | Configure API key and provider |

## 🔑 Supported AI Providers
- OpenAI (GPT-4o, GPT-4)
- Anthropic (Claude 3.5 Sonnet)
- Google Gemini (1.5 Pro, Flash)
- OpenRouter (100+ models)

## 🛡️ Code Shield
Every time you save, Fixora calculates a **PR Readiness Score**:
- ✅ **Ready (80–100)** — clean, ship it
- ⚠️ **Needs Work (50–79)** — some issues to address
- ❌ **Not Ready (0–49)** — significant problems found
