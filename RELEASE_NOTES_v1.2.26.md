# Fixora v1.2.26

## Security & reliability

- Safer workspace writes and stronger protection around symbolic links and project creation.
- Improved migration integrity handling, conversation retention, and desktop test coverage.
- Web chat keeps entered provider keys in memory and safely renders model responses.

## Zappr improvements

- Review file plans before applying; failed multi-file changes are rolled back when possible.
- More reliable cancellation, run isolation, project context, and bounded cross-file repair.

## UI improvements

- Refined workbench surfaces, editor chrome, empty states, context indicators, and command palette.

## Fixes

- Improved filesystem, Git subprocess, update progress, and New Project reliability.

## Known limitation

- Windows binaries in this release are unsigned; SmartScreen may show an Unknown Publisher warning.
